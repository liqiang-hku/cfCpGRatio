# Marker atlas

Place the hg19 U250 marker atlas used in the study in this directory:

`Atlas.U250.l4.hg19.full.tsv`

The atlas file is not included in this starter package. Obtain it from the original source and confirm that redistribution is permitted before committing it to a public repository. The marker atlas should be used with methylation data processed against the same hg19 reference and CpG indexing.
